# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for helping improve this project. This repository is a learning project for Git and GitHub, centered on the `simple-interest.sh` calculator.

## How to contribute

1. Fork the repository and create a branch for your change.
2. Make your update. Keep the simple-interest formula as `(principal * rate * time) / 100`.
3. Test the script with a known example, such as principal `1000`, rate `5`, and time `2`, which should produce simple interest `100.00`.
4. Open a pull request and describe what you changed and why.

## What you can contribute

- **Bug reports** — tell us what you ran, what you expected, and what happened.
- **Bug fixes** — correct calculation, input validation, or script portability issues.
- **Documentation improvements** — clarify README usage, examples, or comments.
- **Enhancements** — small, focused improvements such as clearer prompts or output formatting.
- **Ideas** — open an issue before large changes so we can discuss them.

## Code style

- Write portable Bash and include a shebang.
- Validate that principal, rate of interest, and time period are numeric.
- Do not commit secrets, local environment files, or generated output.

## Code of Conduct

Please follow `CODE_OF_CONDUCT.md` in all issues, pull requests, and discussions.
